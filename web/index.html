Como obter seu Token PAT e App ID na Deriv

1. Gerar Token PAT

Acesse sua conta Deriv em Configurações da Conta > Segurança > Tokens de API. Crie um token com os escopos Read e Trade.

2. Informar App ID

Você pode usar o seu App ID registrado na Deriv ou o App ID padrão do sistema. O App ID conecta a aplicação ao ambiente WebSocket correto.

3. Buscar Contas

Clique em Buscar Contas na Deriv. O sistema listará automaticamente todas as suas contas Real e Virtual para seleção imediata.
